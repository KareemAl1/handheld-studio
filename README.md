# Handheld Studio

An original interactive handheld design by Kareem Alwan. React, TypeScript, Vite, React Three Fiber, and an editable Blender asset.

## Local development

Node 22.12+ and npm are required. Run `npm ci`, then `npm run dev`.

`npm run build`, `npm run lint`, `npm test`, and `npm run test:e2e` provide the verification commands. Browser tests use installed Google Chrome; no bundled browser download is required.
